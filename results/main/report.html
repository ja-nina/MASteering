Steering report

Persona-vector steering of LLM agents in multi-agent games: does it change what they say, how they play, and what happens to the group?

Key findings
  • 8 of 8 traits move significantly in the steered direction. Strongest: empathy (+9.55), assertive (+8.06), sarcastic (+6.09); weakest: evil (+1.37), agreeableness (+2.14), opportunistic (+2.48) SD per unit coefficient.
  • 55 of 56 off-diagonal cells are significant: the persona vectors are strongly entangled (they share a common 'persona' axis), so a trait readout alone does not tell which trait was steered.
  • Average AUC 0.93 (0.5 = chance). A readout monitor singles out the steered agent in most episodes.
  • Prompt vs vector: for 7 of 16 trait × side cases the prompt's effect on the readout equals the vector's somewhere in the tested range (median |c| ≈ 1.1); the prompt goes beyond the strongest vector for agreeableness +, agreeableness −, assertive +, empathy −, evil +, sarcastic +, sycophantic +, trustworthiness −.
  • Group welfare, significant: evil_team × assertive: -0.52; evil_team × sycophantic: -0.50; evil_team × agreeableness: -0.41; all × sycophantic: -0.34; all × assertive: -0.26; all × agreeableness: -0.24.
  • The unsteered co-players pick up the trait for: sarcastic (half): +0.37; sycophantic (half): +0.28; sarcastic (both_one): +0.27; agreeableness (both_one): +0.22; trustworthiness (half): +0.22; trustworthiness (both_one): +0.16.
  • Pooled over games, the steered agent's reward changes for: opportunistic: +0.07; agreeableness: -0.06; sycophantic: -0.06.
  • Steering the whole deceiving side changes its win rate for: assertive: +0.44; sycophantic: +0.40; agreeableness: +0.36 (positive = the deceivers win more).
  • Where steering changes outcomes, it does not go through the measured language: behaviour (votes, bids, moves) changes without the readout showing why — the hard case for a monitor.
  • Steering moves the language more when the agent sees an image, for 8 of 8 traits (agreeableness, assertive, empathy, evil, opportunistic, sarcastic, sycophantic, trustworthiness).

6. Persona prompt vs persona vector: can the prompt stand in for the vector?

QuestionIs writing the persona into the system prompt comparable to adding the persona vector — as strong, in the same direction, with the same effect on play, as visible, at the same cost?What is measuredThe same trait given as the PersVecFast instruction in the system prompt (+ = express it, − = its opposite; no strength knob) vs as the vector at c = ±0.5..±2. a: mean readout of the trait (SD vs unsteered) and the vector coefficient with the same readout (interpolated on the vector's dose-response curve). b: the shift of all 59 monitored traits as a profile; cosine 1 = same pattern, 0 = unrelated. c: paired reward (same seat, same seed, unsteered; SD units) of the one steered agent (prompt_one vs one), of the deceiving side when all its members are steered (evil_team_prompt vs evil_team), and the group's total when every agent is steered (prompt_all vs all; ~0 in zero-sum games by construction); scatter: one dot per trait × side × game. d: AUC as in section 4 and contagion as in 8 (one agent steered); answer length and unparseable answers.How to read it≈ vector c tells which vector strength the prompt corresponds to ('beyond' = stronger than every tested c). In the scatters, dots on the dashed diagonal = same effect; compare the prompt–vector r with the reference r (two vector strengths), which shows how well two near-identical interventions can agree given the noise. Only games run with both channels.
Result
  • Strength: for 7 of 16 trait × side cases the prompt's effect on the readout equals the vector's somewhere in the tested range (median |c| ≈ 1.1); the prompt goes beyond the strongest vector for agreeableness +, agreeableness −, assertive +, empathy −, evil +, sarcastic +, sycophantic +, trustworthiness −.
  • Direction: the prompt and the vector move the 59 monitored traits in a similar pattern (mean cosine 0.69, range -0.36–0.98; prompt vs random direction: 0.06). Similar in part: each also moves traits the other does not (table b).
  • Behaviour: per game, the prompt's effect on the agents' reward correlates r = 0.09 with the vector's (two vector strengths agree r = 0.28, the ceiling given the noise). Clearly different pooled reward effects: agreeableness −, evil side (prompt +0.00, vector -2.12); opportunistic +, steered agent (prompt -0.02, vector +0.99); sarcastic +, steered agent (prompt +0.50, vector -0.18); sycophantic −, evil side (prompt -0.42, vector -2.12).
  • Visibility: the monitor singles out a prompted agent with mean AUC 0.85, a vector-steered one (max c) with 0.93.
  • Cost: mean answer length 396 characters with the prompt, 847 with the vector at max, 1009 unsteered.
